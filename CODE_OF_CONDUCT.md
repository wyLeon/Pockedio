# Code of Conduct

## Our Pledge

We want Pockedio to be a respectful, useful project for people building and using local-first music tools.

Project spaces should be welcoming regardless of age, body size, disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, caste, color, religion, or sexual identity and orientation.

## Expected Behavior

- Use welcoming and inclusive language.
- Respect different viewpoints and experiences.
- Give and accept constructive feedback.
- Focus disagreement on ideas, implementation, and project goals.
- Show empathy toward other community members.

## Unacceptable Behavior

- Harassment, insults, threats, or sustained disruption.
- Sexualized language or imagery.
- Publishing other people's private information without explicit permission.
- Sharing API keys, cookies, diary content, calendar details, or other private user data in public issues or discussions.
- Any conduct that would reasonably make participation unsafe or unwelcome.

## Enforcement

Maintainers may remove comments, issues, pull requests, or other contributions that violate this code of conduct. Maintainers may also temporarily or permanently restrict participation for behavior they judge inappropriate, threatening, offensive, or harmful.

Report conduct concerns through the same private channel described in `SECURITY.md` when privacy or safety matters. For lower-risk moderation concerns, contact a maintainer privately if possible.
