# Pockedio

Personal AI music radio, built CLI-first and then expanded into a web app.

Pockedio is a personal DJ-like music station that adapts to music taste, current intent, schedule context, and mood. The project starts by proving the core product loop in a command-line experience before turning it into a richer web app.

## Current Product Priority

1. Generate a station from current intent, mood, and schedule context.
2. Make the experience feel like a personal DJ with taste, transitions, and lightweight commentary.
3. Learn and reflect personal music taste over time.
4. Support scheduled DJ personas with English as the default DJ language.

## Build Route

1. Define requirements and MVP boundaries.
2. Build a CLI prototype that proves the station-generation loop.
3. Use the CLI behavior as the product contract for the web app.
4. Build the web app UI and playback experience around the validated loop.

Product discovery notes live in [`docs/product-route.md`](docs/product-route.md).
